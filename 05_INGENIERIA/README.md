# 05 - INGENIERÍA

Repositorio de conocimiento técnico y de ingeniería de La Ventanería Ingeniería y Diseño S.A.S.

## Objetivo

Centralizar el conocimiento técnico necesario para diseñar, especificar, calcular, cotizar, fabricar, instalar y validar sistemas arquitectónicos de aluminio y vidrio.

## 6. Normativa

La documentación técnica deberá identificar y mantener actualizadas las normas aplicables.

Se prestará especial atención a:

- NSR-10 y sus actualizaciones o modificaciones vigentes
- Títulos y capítulos aplicables a elementos arquitectónicos
- Requisitos relacionados con vidrio
- Requisitos de seguridad
- Requisitos de viento
- Normas técnicas colombianas aplicables
- Normas internacionales cuando sean utilizadas en especificaciones

Nunca asumir que una versión normativa sigue vigente sin verificarla.

## 16. Reglas fundamentales

1. No inventar especificaciones técnicas.
2. No inventar valores estructurales.
3. No inventar capacidades de perfiles.
4. No inventar propiedades del vidrio.
5. No afirmar cumplimiento normativo sin verificarlo.
6. No utilizar una ficha técnica antigua si existe una versión vigente.
7. Diferenciar siempre entre dato del fabricante, cálculo propio, supuesto y recomendación.
8. Los cálculos críticos deben ser revisados por un profesional competente.
9. Las normas vigentes deben verificarse antes de utilizarlas como fundamento de una decisión técnica.
10. Toda modificación importante debe conservar control de versión.

## 17. Control documental

Cada documento técnico importante deberá identificar:

- Nombre
- Código
- Versión
- Fecha
- Autor
- Revisor
- Aprobador
- Fuente
- Aplicación
- Estado: vigente / obsoleto / en revisión

La versión vigente tiene prioridad sobre versiones anteriores.

## Principio de Ingeniería

La Ingeniería de La Ventanería debe buscar soluciones técnicamente seguras, fabricables, instalables, económicamente viables y coherentes con la propuesta de valor MULTICONFORT.

La prioridad es:

**Seguridad → Cumplimiento → Desempeño → Fabricabilidad → Instalabilidad → Costo → Estética.**
