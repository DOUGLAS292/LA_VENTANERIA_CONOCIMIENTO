- Estado: VIGENTE

- Participantes: Dirección, Arquitectura, Ingeniería estructural, Producción, Instalación, proveedores y profesionales externos, según corresponda

- Documento relacionado: LV-ING-004 — Proceso de Clasificación de Riesgo y Complejidad de Proyectos de Ingeniería

# 2. PROPÓSITO

Establecer una metodología controlada para modelar, calcular, verificar y documentar el comportamiento estructural de los sistemas vidriados de La Ventanería.

El proceso busca demostrar, mediante análisis técnicamente sustentado, que la configuración propuesta satisface los requisitos aplicables de:

- Resistencia.
- Estabilidad.
- Deformación.
- Seguridad.
- Servicio.
- Transferencia de cargas.
- Compatibilidad con las condiciones reales del proyecto.

El cálculo deberá representar razonablemente el sistema que será fabricado e instalado.

---

# 3. PRINCIPIO FUNDAMENTAL

Un cálculo no es únicamente una operación matemática.

Es la representación técnica de una condición física real.

Por tanto:

> MODELO CORRECTO + DATOS CORRECTOS + MÉTODO CORRECTO + INTERPRETACIÓN CORRECTA = VERIFICACIÓN CONFIABLE

Un resultado numérico no deberá considerarse válido si el modelo, los datos de entrada o las hipótesis no representan adecuadamente el proyecto.

# 41. CRITERIOS DE ACEPTACIÓN

La solución podrá considerarse satisfactoria cuando las verificaciones aplicables indiquen cumplimiento de los criterios establecidos.

Deberán identificarse:

- Requisito.
- Criterio.
- Resultado.
- Cumple / No cumple.
- Evidencia.

No deberá utilizarse únicamente la expresión:

**"El cálculo da bien."**

Debe poder demostrarse qué se verificó y frente a qué criterio.

---

# 42. RESULTADO NO SATISFACTORIO

Cuando una verificación no cumpla deberá:

1. Identificarse la causa.
2. Identificarse el componente crítico.
3. Revisarse el modelo.
4. Revisarse los datos.
5. Evaluarse alternativas.
6. Modificarse el sistema si corresponde.
7. Recalcular.
8. Documentar la decisión.

No deberá modificarse un resultado simplemente para obtener cumplimiento.

---

# 43. MARGEN DE SEGURIDAD

# 47. CONFIGURACIÓN CALCULADA VS CONFIGURACIÓN FABRICADA

- Perfil.

- Anclaje.

- Posición del anclaje.
- Secuencia de montaje.

---

# 49. CONTROL DE INSTALACIÓN

Cuando una condición de instalación sea crítica deberá quedar especificada.

Ejemplos:

- Separación de anclajes.

- Profundidad.
- Posición.
- Tolerancias.
- Sellado.
- Apoyos.
- Juntas.

---

# 50. NO LIBERACIÓN

No deberá liberarse un cálculo cuando:

- Los datos críticos sean desconocidos.
- El modelo no represente el sistema real.
- Las acciones no tengan fuente.
- Las propiedades críticas no tengan respaldo.
- Las unidades sean inconsistentes.
- Existan resultados incoherentes.
- Un componente crítico no haya sido verificado.
- Existan incumplimientos sin resolver.
- La configuración calculada no corresponda a la solución que se pretende fabricar.
- Se requiera revisión profesional y esta no haya ocurrido.

- Número de cálculos preliminares.
- Número de cálculos definitivos.
- Tiempo promedio.
- Número de errores detectados.
- Número de recalculaciones.

- Número de cambios posteriores a liberación.
- Número de cálculos reutilizados como referencia.
- Porcentaje de expedientes completos.

# 61. MEJORA CONTINUA

Los resultados de:

- Fabricación.
- Instalación.
- Ensayos.
- Garantías.
- Reclamos.
- Fallas.
- No conformidades.
- Revisiones.

deberán retroalimentar los métodos de cálculo.

Cuando un cálculo haya presentado una deficiencia metodológica deberá registrarse y corregirse.

# 62. REFERENCIAS NORMATIVAS

El cálculo deberá realizarse conforme a la normativa vigente y aplicable al proyecto.

Como marco general podrán resultar relevantes:

- Ley 400 de 1997.
- Reglamento Colombiano de Construcción Sismo Resistente — NSR-10 y sus modificaciones vigentes.
- Decreto 1401 de 2023 y demás modificaciones aplicables.
- Título A, cuando corresponda.
- Título B para cargas y criterios relacionados con acciones, cuando corresponda.
- Título K y disposiciones aplicables a sistemas vidriados.
- Capítulo K.4 cuando resulte aplicable.
- Normas técnicas colombianas aplicables.
- Normas internacionales aplicables cuando correspondan.
- Especificaciones contractuales.
- Información técnica de fabricantes.

La referencia específica utilizada deberá quedar registrada en el expediente.

---

# 63. PRINCIPIO DE REPRODUCIBILIDAD

Un cálculo técnicamente importante deberá poder ser revisado y, en la medida razonable, reproducido por otro profesional competente.

Por tanto, deberá conservarse suficiente información sobre:

- Entradas.
- Método.
- Supuestos.
- Modelo.
- Fórmulas.
- Software.
- Resultados.

La dependencia exclusiva del conocimiento informal de una persona deberá evitarse.

El objetivo del cálculo no es producir una hoja con números.
