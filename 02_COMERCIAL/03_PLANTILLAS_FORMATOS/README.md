# 03 - PLANTILLAS Y FORMATOS

## Propósito

Esta carpeta contiene las plantillas y formatos autorizados para las actividades correspondientes al área Comercial.

## Alcance

Aquí se almacenan estructuras reutilizables para gestionar, documentar, controlar y ejecutar actividades comerciales.

## Contenido

Podrá incluir:

- Plantillas de cotización
- Formatos comerciales
- Modelos de seguimiento
- Matrices comerciales
- Formatos de visitas
- Formatos de seguimiento de oportunidades
- Modelos de reportes
- Otros documentos reutilizables aprobados

## Regla de incorporación

Todo conocimiento nuevo deberá ingresar mediante el pipeline establecido en:

`00_GOBIERNO_CONOCIMIENTO/01_ARQUITECTURA_MAESTRA.md`

Clasificación → Revisión → Aprobación → GitHub.

## Estado de la carpeta

Estructura creada durante la Fase 1 de implementación del Sistema de Gobierno del Conocimiento.

No contiene todavía plantillas o formatos comerciales vigentes.
