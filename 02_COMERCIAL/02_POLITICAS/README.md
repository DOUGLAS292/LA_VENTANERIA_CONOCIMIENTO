# 02 - POLÍTICAS

Esta carpeta contiene las políticas documentadas y vigentes correspondientes al área Comercial.

Aquí se documentan los criterios, reglas y lineamientos que orientan la gestión comercial de La Ventanería Ingeniería y Diseño S.A.S.

## Contenido

Podrá incluir:

- Políticas comerciales
- Criterios de atención y gestión de clientes
- Lineamientos de cotización
- Criterios de negociación
- Condiciones comerciales
- Responsabilidades
- Controles asociados
- Documentos o referencias relacionadas
