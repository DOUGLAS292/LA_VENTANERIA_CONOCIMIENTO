# 03 - PLANTILLAS Y FORMATOS

## Propósito

Esta carpeta contiene las plantillas y formatos autorizados para las actividades correspondientes al área de Marketing.

## Alcance

Aquí se almacenan estructuras reutilizables para planear, ejecutar, documentar y controlar actividades de Marketing.

## Contenido

Podrá incluir:

- Plantillas de campañas
- Briefs de Marketing
- Calendarios de contenido
- Formatos de planificación
- Matrices de campañas
- Formatos de análisis
- Modelos de reportes
- Plantillas de piezas o solicitudes creativas
- Otros documentos reutilizables aprobados

## Regla de incorporación

Todo conocimiento nuevo deberá ingresar mediante el pipeline establecido en:

`00_GOBIERNO_CONOCIMIENTO/01_ARQUITECTURA_MAESTRA.md`

Clasificación → Revisión → Aprobación → GitHub.

## Estado de la carpeta

Estructura creada durante la Fase 1 de implementación del Sistema de Gobierno del Conocimiento.

No contiene todavía plantillas o formatos de Marketing vigentes.
