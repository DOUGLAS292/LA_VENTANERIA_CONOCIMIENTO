# 02 - POLÍTICAS

## Propósito

Esta carpeta contiene las políticas documentadas y vigentes correspondientes al área de Marketing.

## Alcance

Aquí se documentan los criterios, reglas y lineamientos que orientan la planeación, ejecución y control de las actividades de Marketing de La Ventanería Ingeniería y Diseño S.A.S.

## Contenido

Podrá incluir:

- Políticas de comunicación de marca
- Lineamientos de identidad y posicionamiento
- Criterios de publicación
- Lineamientos de campañas
- Criterios de segmentación
- Reglas para el uso de activos de marca
- Responsabilidades
- Controles asociados
- Documentos o referencias relacionadas
