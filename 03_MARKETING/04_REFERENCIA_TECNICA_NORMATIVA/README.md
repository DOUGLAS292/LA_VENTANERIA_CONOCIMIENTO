# 04 - REFERENCIA TÉCNICA Y NORMATIVA

## Propósito

Esta carpeta contiene referencias técnicas, normativas y documentales que sirven como soporte para la gestión de Marketing.

## Alcance

Aquí se documentan referencias relacionadas con Marketing, comunicación, plataformas, herramientas, criterios de contenido y demás información de consulta relevante para el área.

## Contenido

Podrá incluir:

- Referencias técnicas
- Referencias normativas
- Guías de plataformas
- Criterios de comunicación
- Fuentes externas relevantes
- Referencias de herramientas de Marketing
- Resúmenes estructurados de documentos originales

## Regla sobre documentos originales

Los documentos originales sensibles no se almacenan en GitHub.

Cuando corresponda, se conservará únicamente una referencia estructurada hacia su ubicación en la Capa 3.

## Regla de incorporación

Todo conocimiento nuevo deberá ingresar mediante el pipeline establecido en:

`00_GOBIERNO_CONOCIMIENTO/01_ARQUITECTURA_MAESTRA.md`

Clasificación → Revisión → Aprobación → GitHub.
