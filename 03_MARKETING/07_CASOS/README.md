# 07 - CASOS

## Propósito

Esta carpeta contiene casos de Marketing documentados que aporten conocimiento reutilizable para la gestión y toma de decisiones.

## Alcance

Aquí se documentan situaciones reales o antecedentes relacionados con campañas, posicionamiento, comunicación, canales, contenidos y otras actividades de Marketing que permitan conservar aprendizajes.

## Contenido

Cada caso podrá documentar, según corresponda:

- Fecha o período
- Situación presentada
- Contexto
- Objetivo
- Problema o necesidad
- Análisis realizado
- Alternativas consideradas
- Acción adoptada
- Resultado
- Aprendizaje obtenido
- Documentos o referencias relacionadas

## Regla de confidencialidad

Los casos deberán respetar los niveles de clasificación establecidos en:

`00_GOBIERNO_CONOCIMIENTO/02_NIVELES_CONFIDENCIALIDAD.md`

No deberán incorporarse a GitHub datos personales, financieros u otra información sensible que deba permanecer en la Capa 3.

## Regla de incorporación

Todo conocimiento nuevo deberá ingresar mediante el pipeline establecido en:

`00_GOBIERNO_CONOCIMIENTO/01_ARQUITECTURA_MAESTRA.md`

Clasificación → Revisión → Aprobación → GitHub.

## Estado de la carpeta

Estructura creada durante la Fase 1 de implementación del Sistema de Gobierno del Conocimiento.

No contiene todavía casos de Marketing documentados.
