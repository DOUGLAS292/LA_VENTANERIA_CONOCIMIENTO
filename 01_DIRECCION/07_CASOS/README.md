# 07 - CASOS

## Propósito

Esta carpeta contiene casos empresariales documentados que aporten conocimiento reutilizable para la gestión y toma de decisiones del área de Dirección Empresarial.

## Alcance

Aquí se documentan situaciones reales o antecedentes empresariales que permitan conservar aprendizajes, criterios, análisis y experiencias relevantes para la empresa.

## Contenido

Cada caso podrá documentar, según corresponda:

- Fecha o período
- Situación presentada
- Contexto
- Problema o necesidad
- Análisis realizado
- Alternativas consideradas
- Decisión o solución adoptada
- Resultado
- Aprendizaje obtenido
- Documentos o referencias relacionadas

## Regla de confidencialidad

Los casos deberán respetar los niveles de clasificación establecidos en:

`00_GOBIERNO_CONOCIMIENTO/02_NIVELES_CONFIDENCIALIDAD.md`

No deberán incorporarse a GitHub datos personales, financieros, legales u otra información sensible que deba permanecer en los documentos originales de la Capa 3.

Cuando sea necesario, el caso deberá conservar únicamente el conocimiento estructurado y una referencia al documento original.

## Regla de incorporación

Todo conocimiento nuevo deberá ingresar mediante el pipeline establecido en:

`00_GOBIERNO_CONOCIMIENTO/01_ARQUITECTURA_MAESTRA.md`

Clasificación → Revisión → Aprobación → GitHub.

## Estado de la carpeta

Estructura creada durante la Fase 1 de implementación del Sistema de Gobierno del Conocimiento.

No contiene todavía casos empresariales documentados.
