# 08 - ÍNDICE DE DOCUMENTOS RESTRINGIDOS

## Propósito

Esta carpeta contiene únicamente los índices y referencias de documentos originales que, por su nivel de confidencialidad o restricción, no deben almacenarse directamente en GitHub.

## Alcance

El índice permite identificar la existencia, ubicación y responsable de custodia de documentos sensibles que permanecen en la Capa 3 — Google Drive u otra ubicación autorizada.

## Contenido del índice

Cada registro podrá incluir:

- Nombre del documento
- Clasificación
- Ubicación real
- Responsable
- Control de acceso
- Fecha de último control
- Estado

## Regla fundamental

Esta carpeta NO contiene los documentos sensibles originales.

Los documentos originales permanecen en la Capa 3, de acuerdo con la Arquitectura Maestra del Conocimiento.

## Clasificación

Los documentos deberán utilizar los niveles establecidos en:

`00_GOBIERNO_CONOCIMIENTO/02_NIVELES_CONFIDENCIALIDAD.md`

- PÚBLICO
- INTERNO
- CONFIDENCIAL
- RESTRINGIDO

## Control de acceso

La existencia de un índice en GitHub no concede acceso al documento original.

El acceso real deberá estar controlado técnicamente en la ubicación donde se encuentre almacenado el documento.

## Regla de incorporación

Todo conocimiento nuevo deberá ingresar mediante el pipeline establecido en:

`00_GOBIERNO_CONOCIMIENTO/01_ARQUITECTURA_MAESTRA.md`

Clasificación → Revisión → Aprobación → GitHub.

## Estado de la carpeta

Estructura creada durante la Fase 1 de implementación del Sistema de Gobierno del Conocimiento.

No contiene todavía índices de documentos restringidos.
