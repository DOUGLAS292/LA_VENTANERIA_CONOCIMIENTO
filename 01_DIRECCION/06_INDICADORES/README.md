# 06 - INDICADORES

## Propósito

Esta carpeta contiene los indicadores utilizados para medir, controlar y hacer seguimiento a la gestión del área de Dirección Empresarial.

## Alcance

Aquí se documentan indicadores estratégicos y de gestión que permitan evaluar el desempeño, el cumplimiento de objetivos y la evolución de la empresa.

## Contenido

Cada indicador podrá documentar, según corresponda:

- Nombre del indicador
- Objetivo
- Definición
- Fórmula de cálculo
- Unidad de medida
- Fuente de información
- Responsable
- Periodicidad
- Meta
- Resultado
- Análisis
- Acciones derivadas

## Regla de trazabilidad

Los indicadores deberán permitir identificar la fuente de los datos utilizados para su cálculo.

Cuando la información provenga de un documento original o sistema externo, se deberá conservar la referencia correspondiente sin trasladar datos sensibles innecesariamente a GitHub.

## Regla de incorporación

Todo conocimiento nuevo deberá ingresar mediante el pipeline establecido en:

`00_GOBIERNO_CONOCIMIENTO/01_ARQUITECTURA_MAESTRA.md`

Clasificación → Revisión → Aprobación → GitHub.

## Estado de la carpeta

Estructura creada durante la Fase 1 de implementación del Sistema de Gobierno del Conocimiento.

No contiene todavía indicadores empresariales vigentes.
