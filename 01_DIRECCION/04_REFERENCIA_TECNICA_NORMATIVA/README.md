# 04 - REFERENCIA TÉCNICA Y NORMATIVA

## Propósito

Esta carpeta contiene referencias técnicas, normativas y documentales que sirven como soporte para la gestión y toma de decisiones del área de Dirección Empresarial.

## Alcance

Aquí se documentan referencias de consulta que tengan relevancia para las actividades de Dirección.

## Contenido

Podrá incluir:

- Referencias normativas
- Referencias técnicas
- Guías y criterios de consulta
- Documentos de referencia
- Fuentes externas relevantes
- Resúmenes estructurados de documentos originales

## Regla sobre documentos originales

Los documentos originales sensibles no se almacenan en GitHub.

Cuando corresponda, se conservará únicamente una referencia estructurada hacia su ubicación en la Capa 3, de acuerdo con la Arquitectura Maestra del Conocimiento.

## Regla de incorporación

Todo conocimiento nuevo deberá ingresar mediante el pipeline establecido en:

`00_GOBIERNO_CONOCIMIENTO/01_ARQUITECTURA_MAESTRA.md`

Clasificación → Revisión → Aprobación → GitHub.

## Estado de la carpeta

Estructura creada durante la Fase 1 de implementación del Sistema de Gobierno del Conocimiento.

No contiene todavía referencias técnicas o normativas operativas.
