# 02 - POLÍTICAS

## Propósito

Esta carpeta contiene las políticas documentadas y vigentes correspondientes al área de Dirección Empresarial.

## Alcance

Aquí se documentan los criterios, reglas y lineamientos que orientan la toma de decisiones y la gestión de La Ventanería Ingeniería y Diseño S.A.S.

## Contenido

Las políticas podrán documentar, según corresponda:

- Principios de actuación
- Criterios de gestión
- Reglas internas
- Lineamientos para la toma de decisiones
- Responsabilidades
- Controles asociados
- Documentos o referencias relacionadas

## Regla de incorporación

Todo conocimiento nuevo deberá ingresar mediante el pipeline establecido en:

`00_GOBIERNO_CONOCIMIENTO/01_ARQUITECTURA_MAESTRA.md`

Clasificación → Revisión → Aprobación → GitHub.

## Estado de la carpeta

Estructura creada durante la Fase 1 de implementación del Sistema de Gobierno del Conocimiento.

No contiene todavía políticas operativas vigentes.
