# 03 - PLANTILLAS Y FORMATOS

## Propósito

Esta carpeta contiene las plantillas y formatos autorizados para las actividades correspondientes al área de Dirección Empresarial.

## Alcance

Aquí se almacenan estructuras reutilizables para documentar, gestionar, controlar o ejecutar actividades propias de Dirección.

## Contenido

Podrá incluir:

- Plantillas de documentos
- Formatos de gestión
- Modelos de seguimiento
- Matrices
- Estructuras de reportes
- Formatos de toma de decisiones
- Otros documentos reutilizables aprobados

## Regla de incorporación

Todo conocimiento nuevo deberá ingresar mediante el pipeline establecido en:

`00_GOBIERNO_CONOCIMIENTO/01_ARQUITECTURA_MAESTRA.md`

Clasificación → Revisión → Aprobación → GitHub.

## Estado de la carpeta

Estructura creada durante la Fase 1 de implementación del Sistema de Gobierno del Conocimiento.

No contiene todavía plantillas o formatos operativos vigentes.
