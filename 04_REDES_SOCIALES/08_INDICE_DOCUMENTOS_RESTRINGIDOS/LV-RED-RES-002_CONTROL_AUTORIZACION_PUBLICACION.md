# 1. PROPÓSITO

Establecer el control previo para determinar si información proveniente de documentación interna o restringida puede utilizarse en contenido público.

---

# 2. PRINCIPIO

Que una información esté disponible internamente no significa que esté autorizada para publicación.

---

# 4. CRITERIOS

Antes de autorizar deberá evaluarse:

- Confidencialidad.
- Datos personales.
- Propiedad intelectual.
- Información del cliente.
- Información del proyecto.
- Información técnica.
- Información comercial.
- Riesgo reputacional.
- Autorizaciones existentes.

---

# 5. RESULTADOS

### APROBADO

Puede utilizarse dentro del alcance autorizado.

### APROBADO CON CONDICIONES

Puede utilizarse únicamente bajo las condiciones registradas.

### POR VALIDAR

No debe publicarse todavía.

### RECHAZADO

No está autorizado para publicación.

### RESTRINGIDO

No debe utilizarse públicamente.

---

# 6. ANONIMIZACIÓN

Cuando sea posible, un caso podrá convertirse en contenido eliminando:

- Identidad del cliente.
- Ubicación específica.
- Valores.
- Datos personales.
- Información propietaria.

La anonimización deberá ser suficiente para evitar identificación indebida.

---

# 7. IA

Claude podrá ayudar a identificar posibles riesgos de publicación.

La IA no sustituye la autorización empresarial.
