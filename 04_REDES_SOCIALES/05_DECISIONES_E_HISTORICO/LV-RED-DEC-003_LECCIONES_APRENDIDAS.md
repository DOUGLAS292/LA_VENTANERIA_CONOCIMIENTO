# 1. PROPÓSITO

Conservar aprendizajes obtenidos de la operación de Redes Sociales para evitar repetir errores y aumentar progresivamente la efectividad del área.

---

# 2. PRINCIPIO

Una lección aprendida debe poder convertirse en una mejora futura.

No se trata únicamente de registrar:

> “Esto funcionó.”

Debe registrarse:

> “Esto funcionó bajo estas condiciones y por estas razones.”

# 4. TIPOS DE APRENDIZAJE

### CONTENIDO

Aprendizajes sobre temas, formatos y mensajes.

### AUDIENCIA

### MARCA

Aprendizajes derivados de preguntas o contenidos técnicos.

# 5. ESTRUCTURA

Cada aprendizaje importante debería procurar responder:

1. ¿Qué ocurrió?
2. ¿Qué observamos?
3. ¿Por qué creemos que ocurrió?
4. ¿Qué aprendimos?
5. ¿Qué debemos hacer diferente?
6. ¿Qué debemos repetir?
7. ¿Qué evidencia respalda la conclusión?

---

# 6. APRENDIZAJES SOBRE CONTENIDO

Podrán registrarse aprendizajes relacionados con:

---

# 7. APRENDIZAJES SOBRE PÚBLICOS

Deberán identificarse patrones relacionados con:

- Arquitectos.
- Diseñadores.
- Constructoras.
- Ingenieros.
- Cliente premium.
- Empresas.
- Instituciones.

El objetivo es comprender qué información necesita cada público.

---

# 8. APRENDIZAJES SOBRE LEADS

Deberán observarse:

- Fuente.
- Tipo de solicitud.
- Nivel de interés.
- Necesidad.
- Presupuesto cuando esté disponible.
- Proyecto.
- Calidad.
- Conversión.

No deberán registrarse datos personales innecesarios.

---

# 9. APRENDIZAJES NEGATIVOS

También deberán conservarse:

- Campañas que no funcionaron.
- Mensajes que generaron confusión.
- Contenidos con baja respuesta.
- Errores de segmentación.
- Errores de proceso.
- Problemas de coordinación.

El objetivo es evitar repetirlos.

---

# 10. APRENDIZAJES SOBRE MULTICONFORT

Deberá registrarse qué dimensiones generan mayor interés:

- Acústica.
- Térmica.
- Visual.
- Ergonomía.
- Protección.
- Diseño.
- Bienestar.

La evidencia deberá orientar la evolución del contenido.

---

# 11. CONVERSIÓN EN REGLA

Una lección aprendida no se convierte automáticamente en política.

Para convertirse en regla deberá:

1. Ser suficientemente consistente.
2. Tener evidencia.
3. Ser revisada.
4. Ser aprobada cuando corresponda.
5. Incorporarse al documento adecuado.

---

# 12. USO DE IA

Claude podrá consultar las lecciones para:

- Identificar patrones.
- Detectar aprendizajes repetidos.
- Proponer experimentos.
- Evitar errores anteriores.
- Recomendar mejoras.

No deberá convertir una sola observación en una verdad universal.

# 13. PRINCIPIO DE APRENDIZAJE CONTINUO

Redes Sociales deberá funcionar como un sistema:

**OBSERVAR → MEDIR → APRENDER → AJUSTAR → PROBAR → MEDIR NUEVAMENTE**
