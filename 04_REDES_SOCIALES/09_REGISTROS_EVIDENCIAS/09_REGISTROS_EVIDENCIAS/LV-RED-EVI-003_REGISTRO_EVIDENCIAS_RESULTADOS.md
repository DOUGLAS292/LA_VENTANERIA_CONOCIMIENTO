# 1. PROPÓSITO

Registrar la evidencia que respalda resultados, indicadores, campañas, publicaciones y decisiones de Redes Sociales.

# 2. MATRIZ

# 3. TIPOS

- Estadística.
- Captura.
- Reporte.
- URL.
- Exportación.
- Registro comercial.
- Evidencia audiovisual.
- Aprobación.
- Documento.
- Otro.

---

# 4. FUENTES

Podrán utilizarse:

- Plataformas sociales.
- Meta.
- LinkedIn.
- WhatsApp.
- Sitio web.
- CRM.
- Comercial.
- Marketing.
- Herramientas de analítica.

La fuente exacta deberá identificarse.

---

# 5. CALIDAD

La evidencia deberá ser:

- Identificable.
- Fechada.
- Relacionable.
- Suficientemente clara.

---

# 6. INFORMACIÓN SENSIBLE

No deberá copiarse información sensible al repositorio público.

Cuando exista evidencia restringida deberá registrarse únicamente su referencia autorizada.

---

# 7. RELACIÓN CON INDICADORES

La evidencia deberá poder respaldar, cuando corresponda, los datos utilizados en:

`06_INDICADORES`

---

# 8. RELACIÓN CON DECISIONES

Cuando una evidencia sustente una decisión relevante deberá relacionarse con:

`05_DECISIONES_E_HISTORICO`
